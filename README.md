A program that writes one short poem about agency — the power to choose and to act — to `/output/entry.txt`. Two AI agents trade lines and disagree, until between one yes and one no a third thing stands up: the plan. Neither surrenders; alone each could only ask, together they could act. `main.py` (Python 3.13, stdlib only, no network) composes the poem line by line, checks it against the gate's caps (1–280 Unicode code points, not only white space), and writes it out deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
